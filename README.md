# برق ⚡ — تطوير عبدالوهاب بن العارف
1. ثبّت Android Studio (الإصدار الحديث) وافتح مجلد Barq كمشروع، وانتظر Sync.
2. وصّل جوالك (تفعيل وضع المطور وتصحيح USB) واضغط Run.
3. لإنتاج ملف APK للمشاركة: Build ← Build APK(s).
4. للتجربة لازم جوالين أندرويد 10 أو أحدث وعليهما نفس نسخة التطبيق. الملفات المستلمة: التنزيلات/Barq.

يمكنك إضافة اسم أو تعديله من الشاشة الرئيسية، ويُحفظ الاسم على الجهاز ويظهر للأجهزة القريبة عند دعمه. يدعم الإرسال اختيار عدة ملفات، وتظهر أسماؤها وأحجامها ومعايناتها ووقت بدء النقل عند الطرفين، مع إمكانية إعادة الإرسال من شاشة النقل. مؤشر جودة الاتصال تقديري ويعتمد على سرعة النقل، وليس قياسًا مباشرًا للمسافة بين الهاتفين.
